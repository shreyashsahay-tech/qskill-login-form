# QSkill Internship - Login Form

A responsive login form created as part of the QSkill Internship Slab 1 task.

## Internship Task

Create a login form using HTML, CSS and JavaScript with form validation using JavaScript and alert messages for results and errors.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive login form
- Email validation
- Password validation
- Minimum 6-character password validation
- JavaScript alert messages
- Success message after valid input
- Clean and simple user interface

## Validation

The form checks:

1. Empty email
2. Invalid email format
3. Empty password
4. Password shorter than 6 characters
5. Successful form validation

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Test the login form.
